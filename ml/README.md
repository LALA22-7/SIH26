## Training

### Prerequisites

- `data/training_manifest.csv` must exist (generated by `scripts/validate_and_join.py`)
- `data/normalized/<event>/frames/*.npz` must exist (generated by `scripts/standardize_data.py`)
- 122 frames are already committed in `data/normalized/` — training can start immediately

### Run training

```bash
# From repo root
python -m ml.src.train
```

This:
1. Reads `data/training_manifest.csv`
2. Filters rows with valid `center_lat` / `center_lon`
3. Splits into train/val using a fixed seed (reproducible)
4. Trains `CycloneCNN` for 20 epochs
5. Saves checkpoint to `ml/checkpoints/model.pt`

Training output per epoch:
```
Epoch [1/20] train_loss=0.0842 val_loss=0.0917
```

### Config flags (in `ml/src/train.py`)

| Flag | Default | Change when |
|---|---|---|
| `PREDICT_PATTERN` | `False` | Research delivers ground-truth label CSV and labels are joined into manifest |
| `NUM_EPOCHS` | `20` | Increase if val_loss is still decreasing |
| `BATCH_SIZE` | `4` | Increase on GPU (try 16 or 32) |
| `LEARNING_RATE` | `0.001` | Reduce to `0.0001` if val_loss is unstable |

**Do not set `PREDICT_PATTERN=True` until `pattern_label` values in `training_manifest.csv` are no longer `"unlabeled"`.**

## Architecture

```
Input [B, 2, H, W]   (B=batch, C=2 channels, variable H/W)
        │
    Conv2d(2→16) + ReLU + MaxPool2d
        │
    Conv2d(16→32) + ReLU + MaxPool2d
        │
    AdaptiveAvgPool2d(16×16)   ← handles any input spatial size
        │
    Flatten → Linear(32×16×16 → 128) + ReLU
        │
    ┌───────────────────────────────────┐
    │ fc_center  → [B, 2]  (lat, lon)  │  ← always active
    │ fc_pattern → [B, 5]  (5 classes) │  ← only when predict_pattern=True
    │ fc_confidence → [B, 1] (sigmoid) │  ← only when predict_confidence=True
    └───────────────────────────────────┘
```

`AdaptiveAvgPool2d` is the key design choice — the real satellite crops come out at slightly different H×W depending on the geographic bounding box, so a fixed pooling size would crash. The adaptive pool makes the model input-size agnostic.

## Wiring to the backend

The backend's `ml_adapter.py` auto-detects the `ml` package. No manual wiring is needed — just make sure the package is importable from the container.

### In Docker (dev)

The `docker-compose.yml` already mounts `../ml:/ml` and sets `PYTHONPATH=/ml:/app`. The backend will switch to real mode automatically once `ml/checkpoints/model.pt` exists.

Confirm real mode is active:
```bash
docker compose exec api python -c "
from app.services.ml_adapter import _get_mode; print(_get_mode())
"
# Should print: real
```

If it prints `stub`:
1. Check `ML_FORCE_STUB=false` in `.env`
2. Check `ml/checkpoints/model.pt` exists
3. Restart: `docker compose restart api`

### Locally (without Docker)

```bash
# From repo root, with ml/ on PYTHONPATH:
PYTHONPATH=. python -c "
from ml.inference import predict_frame
import numpy as np
frame = np.zeros((2, 286, 357), dtype='float32')
print(predict_frame(frame))
"
```

Expected output:
```python

  'center': {'lat': 11.8, 'lon': 145.3},   # untrained values — train first
  'pattern': {'label': 'unlabeled', 'confidence': None},
  'model': {'name': 'ps70-classifier', 'version': '1.0.0'}
```

## Known limitations

- Centre prediction only — pattern head untrained until Research delivers labels
- Persistence-based temporal prediction — no trained temporal model yet
- Trained on 2 events (88 + 34 = 122 frames) — small dataset, overfitting risk
- Per-frame min-max normalisation — not dataset-wide statistics (acceptable for prototype)
- No visible channel — GridSat-B1 provides IR + WV only
- Flat-earth error metric in evaluate.py — use backend `/api/metrics` for proper Haversine MAE
